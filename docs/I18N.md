# Hướng dẫn đa ngôn ngữ (i18n)

Vivu Travel hỗ trợ đa ngôn ngữ để phục vụ khách hàng trong nước và quốc tế. Dự án sử dụng thư viện `next-intl` (Next.js Internationalization).

## 🌐 Ngôn ngữ hỗ trợ

Hiện tại hệ thống hỗ trợ 2 ngôn ngữ:
- **Tiếng Việt (`vi`)**: Ngôn ngữ mặc định.
- **Tiếng Anh (`en`)**.

## 📁 Cấu trúc tệp bản dịch

Các chuỗi văn bản bản dịch được lưu trữ tập trung tại thư mục `src/messages/`:
- `vi.json`: Bản dịch Tiếng Việt.
- `en.json`: Bản dịch Tiếng Anh.

> Các tệp JSON này được cấu trúc theo phân cấp (Namespace) để dễ dàng quản lý.

## 🛠️ Cách sử dụng

### 1. Trong Client Component
Sử dụng hook `useTranslations`:
```tsx
'use client';
import { useTranslations } from 'next-intl';

export function MyComponent() {
  const t = useTranslations('Namespace');
  return <h1>{t('key')}</h1>;
}
```

### 2. Trong Server Component
Sử dụng hàm async `getTranslations`:
```tsx
import { getTranslations } from 'next-intl/server';

export default async function Page() {
  const t = await getTranslations('Namespace');
  return <div>{t('title')}</div>;
}
```

### 3. Middleware & Routing
- Ngôn ngữ được xác định dựa trên prefix URL (ví dụ: `/vi/hotels` hoặc `/en/hotels`).
- `src/middleware.ts` xử lý việc tự động nhận diện ngôn ngữ của trình duyệt hoặc cookie để điều hướng người dùng đến locale phù hợp.

## 🔄 Chuyển đổi ngôn ngữ

Component **`LocaleSwitcher`** (`src/components/locale-switcher.tsx`) được tích hợp trên Navbar để người dùng có thể dễ dàng thay đổi ngôn ngữ bất cứ lúc nào. Khi thay đổi, hệ thống sẽ lưu locale vào Cookie để ghi nhớ cho các lần truy cập sau.

## ➕ Thêm bản dịch mới

1. Mở tệp `src/messages/vi.json` và thêm key mới vào namespace tương ứng.
2. Mở tệp `src/messages/en.json` và thêm key tương tự với nội dung tiếng Anh.
3. Sử dụng `t('namespace.key')` trong mã nguồn.
